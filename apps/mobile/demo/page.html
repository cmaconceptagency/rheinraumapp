Testideen

  1. Baustelle wählen → Standort prüfen & einstempeln → Pause → Fortsetzen → Arbeitsende.
  2. Standort „Außerhalb“ oder „Ungenau“ wählen und einstempeln: verständliche Ablehnung, „Erneut prüfen“, „Korrektur beantragen“.
  3. Offline gehen, Pause buchen, wieder online gehen: automatische Übertragung ohne Duplikate.
  4. App neu laden, während die Zeit läuft: der Timer läuft weiter.
  5. Unter „Baustellen“ die Entfernung vom Wohnort berechnen (einfache Strecke, simuliert).
  6. Unter „Berichte“ einen Bericht mit Foto aus der Galerie anlegen; unter „Mehr“ eine Krankmeldung ohne Diagnose.

Demo zurücksetzen

Löscht alle in dieser Demo erfassten Daten und lädt die Beispieldaten neu.

Hinweis: Diese Demo läuft vollständig im Browser. Der echte Server (mit PostgreSQL-Datenbank, Rollen und Admin-Oberfläche) ist im Projekt enthalten, wird hier aber durch eine Simulation ersetzt. Auf dem Telefon nutzt die App das echte GPS. Daten bleiben nur in diesem Browser gespeichert.
